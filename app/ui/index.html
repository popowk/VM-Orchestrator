自动更新安全机制

        
① 获取 Release
只读取配置仓库的稳定版本，不接受任意下载地址。

        
② 完整性校验
ZIP 必须与同一 Release 的 .sha256 校验文件一致。

        
③ 备份与升级
保存现有程序副本；数据库、证书、凭据和虚拟机保持原样。

        
④ 重启与回滚
服务健康检查失败时恢复旧程序并尝试重启。

        
公开仓库可直接检查更新；仅私有仓库需要在 Windows 宿主机配置只读 Token。
