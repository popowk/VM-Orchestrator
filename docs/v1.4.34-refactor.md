# VM Orchestrator v1.4.34 重构与精简记录

基础版本：用户提供的 v1.4.33（Customer Announcements & Quotas）。输出版本：v1.4.34。

## 文件与功能审查

| 部分 | 已发现问题 | 当前处理 |
|---|---|---|
| Host/Gateway 启动 | 旧版 Host Agent / Guest Gateway 分别运行 PowerShell + Uvicorn | 保留单一主启动命令，改由一个 Python PID 承载两个互相隔离的 FastAPI 服务。先启动 Guest HTTPS，再启动 Host HTTP |
| Guest Agent 源码 | `guest_agent` 与 `Windows10-Template-Tools/Guest-Agent-Template` 有 30 多项逐字节相同的文件 | 移除模板目录副本，统一使用 `guest_agent/`，按需生成 Windows 10 模板安装工具包 |
| OOBE / Sysprep 脚本 | `scripts/guest` 与模板工具目录同名脚本重复 | 将 `scripts/guest/` 作为唯一源码，模板包在创建时复制依赖 |
| 思博客户管理 | 映射、自助操作、公告、额度、客户列表、迁移绑定内容纵向堆叠，部分产品清单重复读取 | 重新布局五个工作区；增加指标、搜索、筛选和快捷修改额度；自助模块复用已获取的商品数据 |
| 调试与测试文件 | 17 个测试脚本、旧版联调脚本、两套旧启动文件及历史发行清单随生产包发布 | 仅保留运维所需状态检查和诊断功能；开发测试脚本不再随正式 ZIP 发布；过时启动脚本归档 |
| 意外数据库文件 | 原始 ZIP 含一份 `D:\VMware\VM-Orchestrator\data\templates.sqlite3` | 已从新发布包排除，不分发数据或密钥 |

**规模：** 原 ZIP 209 个文件、未压缩约 1636.6 KiB；新发布包 141 个文件、未压缩约 897.3 KiB（减少 45.2% 原始文件体积）。

## 合并边界与保留功能

- 保留端口 8765（管理员 HTTP）、8766（Guest HTTPS）、独立的访问控制与 TLS。两个服务**不能**合并为同一个供客户访问的应用路径。
- 保留商品模板绑定、客户实例开通/续费/到期处理、到期强制关机、一次性预览、客户公告（新公告必展示一次）、单用户额度、月度恢复/重装限制、操作排序及执行记录、软件升级/回滚、Guest WSS 和远程运维。
- 不合并 Host 与 Guest 的 API 权限、数据库授权逻辑或密钥身份。`app/update_commands.py` 与 `guest_agent/update_commands.py` 虽内容相同，但部署到不同的主机环境，独立分发是必须的。
- “单进程”严格指一个 **Python 后端进程**；启动 `.cmd`/PowerShell 包装器、VMware 的 `vmrun.exe`、客户虚拟机中的 Guest Agent，以及按需执行的安装/远程命令仍然会各自创建进程，不能安全地合并到后端中。

## 安装与升级

1. **关闭原 8765 和 8766 两套服务**，确认两个端口均没有监听；备份现有 `D:\VMware\VM-Orchestrator`、虚拟机目录与数据库。
2. 解压 `VM-Orchestrator-v1.4.34-Unified-Refactored.zip` 到不同于安装目录的路径，运行 `Install-All.cmd`。安装器会为已有安装建立 `backup-before-v1.4.34-*`，并保留原有数据、DPAPI 密钥及 VMware 文件。
3. 使用同一 Windows 交互用户运行 `Start-VM-Orchestrator.cmd`，查看两个端口的启动输出。管理端 `http://127.0.0.1:8765`，Guest 网关由 `data/guest-network.json` 中的宿主机 IPv4 决定（默认 `192.168.2.99:8766`）。
4. 在爱快和 Windows 防火墙上继续限制 Guest 子网访问 8766，并禁止 Guest 子网访问管理端 8765。**单进程合并减少了进程隔离层，尤其不能因此放宽路由和防火墙策略。**
5. 如果需要新做黄金模板，可直接取独立 `VMO-Win10-Template-Kit-v1.4.34.zip`，或在宿主机运行 `Create-Win10-Template-Kit.cmd`，将生成的 `dist/Windows10-Template-Tools` 整体复制到 **未封存 BUILD 克隆机**。严禁在生产客户机上执行 Sysprep 封装。
