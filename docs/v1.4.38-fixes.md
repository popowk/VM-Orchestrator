# VM Orchestrator v1.4.38 修复说明

基于 v1.4.37 的增量修复，默认升级目录为 D:\VMware\VM-Orchestrator。

## 客户操作

1. 自助操作按钮始终显示「执行操作」，选中操作即可发起；移除“查看执行限制”按钮和客户警告框。
2. `UNKNOWN`、`TIMED_OUT`、`VERIFY_REQUIRED` 为历史状态，不再阻塞新的客户自助操作，也不影响此前操作冷却。
3. `RESERVING`、`QUEUED`、`CLAIMED`、`RUNNING` 仍受事务级互斥保护，防止同一虚拟机正在处理两条命令；相同 request_id 保持幂等。
4. 管理员可继续在「客户自助 → 客户执行任务」查看未知结果，按钮改为「标记已核对」，但它不再是解锁前置条件。
5. 最近执行记录、最近任务、客户公告换行和模板回退等 v1.4.37 功能全部保留。

## 风险提醒

超时或未知状态不能证明客户端程序已停止。新版本按要求取消审核阻塞，因此再次运行同一高权限命令可能产生重复动作。建议将经客户触发的操作配置为幂等命令，并根据执行日志判断是否需要人工核对。

## 升级和缓存

请先停止 8765 / 8766，备份原安装目录及 SQLite 数据库，再从独立解压目录运行 Install-All.cmd。安装后启动 Start-VM-Orchestrator.cmd，在客户端按 Ctrl+Shift+R，确认 `/ui/client.js?v=1.4.38` 生效。不需要重新封装 Win10 模板或修改 Guest Agent。
