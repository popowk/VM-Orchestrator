# VM Orchestrator v1.4.36 更新说明

基于 v1.4.35 精简版，保留原管理后端（8765）与 Guest HTTPS/WSS 网关（8766）单进程双监听架构；没有更改思博对接、实例、数据库或自助操作数据格式。

## 变更一：远程运维命令限制提升

原版：网页 `maxlength=2000`、Host `RemoteStore.queue` 2000 字符、Guest Agent V2 `execute_op` 2000 字符、Host 参数总长 9000。

v1.4.36：CMD 命令最多 **8000 字符**，PowerShell 命令最多 **12000 字符**；Host 对 COMMAND 类型允许最多 **64 KiB** 的 UTF-8 JSON 参数，其他操作仍保留原有 9000 字节限制。Host 与 Guest 双边按命令环境校验，Windows 命令行实际长度仍做二次检查；保留管理员身份鉴权、显式确认、WSS 纳管、单任务执行和审计。

**Guest Agent 同步更新至 v2.0.21。** 已运行旧版 Agent 的虚拟机，命令超过 2000 字符前必须在「远程运维」选择实例并点「从宿主机升级 Guest Agent」，等待显示安装版本 2.0.21。升级安装包使用已有 WSS 安全渠道及签名/校验机制，保留系统与身份数据；升级会短暂中断 WSS。

如果命令更长或涉及大量中文、引号、多段脚本，推荐先通过远程运维上传 `.ps1` 到例如 `C:\dsh\`，然后用短命令 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\dsh\script.ps1"` 调用。CMD 约 8191 字符、Windows CreateProcessW 约 32767 UTF-16 代码单元的系统限制仍然存在；扩大输入框不代表可以绕过操作系统限制。

## 变更二：WSS 连接诊断上方的画面预览

远程运维右侧新增小预览窗；默认关闭，按「开启预览」后立即获取首帧，并**每隔 1000ms 尝试获取新帧**。慢截图不重叠；实际刷新频率可能受 VMware/VNC 采集耗时影响。关掉开关、切换 VM、切换页面、浏览器标签页进入后台或退出登录会取消请求与撤销图片缓存 URL，不继续在后台截图。

复用原有 `capture_loopback_vnc` 和 VMware VMX 本机 VNC `127.0.0.1` 端口。提供独立只读路由 `GET /api/vms/{vm_id}/screen-preview.jpg`，仅通过受管理员保护的 8765 管理端访问；限制 960×540 JPEG，质量 62，`no-store`，不写入服务器磁盘。**不在 Guest 端口 8766 暴露路由，不新增公网端口，不创建远程键鼠控制通道。**

如果提示「请先在虚拟机关机时点击启用本机截图」，按「虚拟机」页面旧流程操作：关机→开启本机截图→开机。克隆向导默认勾选自动启用本机截图的 VM 一般已具有这项能力。VNC 协议较旧，只能绑定宿主机回环地址，不能放开 VNC 端口到局域网。

## 安装升级

1. 停止旧版 8765/8766 服务，并备份正式安装目录、`data/`、虚拟机磁盘；升级前确保本机没有运行中的安装服务进程。
2. 把 `VM-Orchestrator-v1.4.36-LongCommands-LivePreview.zip` 解压到**正式安装目录以外**；以原有管理员方式执行 `Install-All.cmd`。
3. 安装器会创建带时间戳的旧目录备份并保留 `.env`、数据库、TLS/DPAPI 密钥及客户 VM。重启 `Start-VM-Orchestrator.cmd`，浏览器用 `Ctrl+Shift+R` 强制刷新。
4. 在远程运维页面选择已纳管实例，查看 Agent v2.0.21 可升级提示；先升级一个测试虚拟机验证超长命令。
5. 检查选定虚拟机截图功能已启用并开机，手动开启预览；确认关闭预览或换页面后停止轮询。

Windows 10 模板工具包随附 v2.0.21 Agent 源文件；已经封存的黄金模板**不需要**仅为本次管理端预览功能重新 Sysprep。模板仍应使用独立的模板工具包管理。

## 已执行的验证

- Python 全部源码可编译、管理端 JS 的 Node 语法检查通过。
- Guest Agent v2.0.21 升级 ZIP 清单生成通过，升级引导命令仍在旧版 Agent 的 2000 字符限制以内。
- Host DB/Guest 的 CMD 8000 与 PowerShell 12000 字符边界和越界拒绝测试通过；12000 个中文字符的 Host 入队通过。
- 模拟 VMware VMX 的 Host HTTP 接口：匿名请求 401、管理端 200 JPEG+no-store、VNC 未启用返回 503。
- Chromium 离线界面验证：PowerShell 10000 字符输入可用、CMD 超长禁用、截图按秒轮询、关闭后停止、离开页面后停止；没有 JS 页面异常。
- **未**在真实 Windows 10/11 + VMware Workstation 宿主机上验证 VNC 抓屏图像、长 PowerShell 实际执行及 Guest Agent 原地升级。升级生产前先测一台客户测试 VM。

## 不变的安全边界

仅宿主机管理员能够执行远程命令，命令必须通过已注册 Guest WSS 连接。预览不提供键鼠控制；单进程不意味着合并 8765/8766 的访问权限或开放 VNC。
